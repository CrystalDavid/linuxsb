# UI 设计规范

本文件是烧饼社区视觉 token 与共享组件的规范源。实现值以 `DesignSystem.ets`、共享组件和资源颜色为准；页面不得通过局部魔法数字悄悄建立第二套视觉系统。

## 设计原则

- 简约、蓝色、HarmonyOS 原生；背景保持单一层级，交互层才使用玻璃。
- 一个控件只允许一个 `backgroundEffect` 采样层、一个细边缘和一圈中性阴影。
- 选中状态依靠品牌蓝文字/图标、极淡选中胶囊和局部蓝光表达，不使用厚白填充。
- 深色模式必须降低白边与白色填充，不能把玻璃做成发亮的银色描边。
- 正常业务图标优先使用系统 `SymbolGlyph`；需要精确轮廓时使用 ArkUI `Path`，不使用位图模拟可参数化图标。

## 字号体系

业务文字固定为以下 **12 种字号**。`SymbolGlyph`、`Path`、头像首字母和纯图标的几何尺寸不计入业务文字字号；新增 `Text`、`Button`、`TextInput`、`TextArea` 时必须引用 `Typography` token。

| Token | 字号 | 场景 | 常用字重 |
| --- | ---: | --- | --- |
| `MICRO` | 11vp | 底栏标签、极小状态、次级徽标 | Regular / Medium |
| `CAPTION` | 12vp | 说明、板块简介、加载提示、标题栏分段标签 | Regular；选中 Medium |
| `METADATA` | 13vp | 作者、回复数、时间、普通标签、代码正文 | Regular |
| `BODY_SMALL` | 14vp | 辅助正文、筛选 Chip、作者优先副层 | Regular / Medium |
| `BODY` | 15vp | 正文、输入、普通操作文字 | Regular |
| `LIST_TITLE` | 16vp | 紧凑主题流、折叠小标题 | Regular / Bold |
| `TOPIC_TITLE` | 17vp | 首页主题、板块名称、具体板块主题 | Medium（500） |
| `SECTION_TITLE` | 18vp | 页面内分区标题、登录门禁标题 | Medium / Bold |
| `CONTENT_TITLE` | 20vp | 用户名、空状态标题、内容级标题 | Bold |
| `PAGE_TITLE` | 22vp | 首页、板块、搜索、我的、设置、发表、详情、登录标题栏 | Bold |
| `HEADLINE` | 24vp | 主题详情主标题、展示级头像字母 | Medium / Bold |
| `DISPLAY` | 26vp | 诊断页展示标题 | Bold |

正文默认行高为 23vp，长文阅读行高为 25vp。兼容别名只能映射到上述 token，不得产生第 13 种业务字号。

## 间距与圆角

| 类型 | Token / 值 | 用途 |
| --- | --- | --- |
| 间距 | 4 / 6 / 8 / 12 / 16 / 20 / 24 / 32vp | 从局部紧凑间距到页面分区间距 |
| 页面横向边距 | 12vp | 手机主内容安全边距 |
| 圆角 | 6 / 8 / 12 / 18vp | 小标签、内容块、卡片、较大容器 |
| 满圆胶囊 | `Radius.PILL` | 分段、玻璃按钮、圆形操作 |
| 手机内容最大宽度 | 720vp | 列表与普通页面 |
| 详情内容最大宽度 | 840vp | 主题详情 |
| 平板双栏断点 | 900vp | 小于此值保持单栏 |

## 色彩

### 基础语义色

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 页面背景 | `#F8FAFC` | `#0B0F12` |
| 主文字 | `#17202A` | `#F1F5F8` |
| 次文字 | `#556270` | `#B1BCC6` |
| 品牌蓝 | `#0A59F7` | `#5B8FF9` |
| 品牌软背景 | `#E8F1FF` | `#1B3158` |

### 状态胶囊

- 置顶：蓝；精华：紫；热：红；抽奖中：粉；进行中卡片：青；已结束卡片：灰。
- 标签文字和软背景必须成对使用；深色模式使用专用高对比资源，不能直接复用浅色前景。
- 不得用同一种灰色代替所有业务状态。

## 共享玻璃参数

所有正式玻璃控件复用 `buildImmersiveGlassEffect()`：

| 参数 | 规范值 |
| --- | ---: |
| 采样半径 | 6vp |
| 饱和度 | 1.08 |
| 亮度 | 1.12 |
| 外边缘 | 1.25vp |
| 外阴影 | 半径 16vp，Y 偏移 4vp |
| 选中层边缘 | 0.9vp |
| 选中层阴影 | 半径 7vp，Y 偏移 1vp |

### 底部 Tab 托盘主玻璃

悬浮底栏是唯一的“主玻璃”表面，使用更深一层的霜化采样，让滚动内容融化成柔和色场：

| 参数 | 规范值 |
| --- | ---: |
| 采样半径 | 24vp |
| 饱和度 | 1.15 |
| 亮度 | 1.35 |
| 采样 tint | `bottom_tab_bar_frost`（浅色 `#33FFFFFF` / 深色 `#18000000`） |

托盘的按钮、移动指示器、图标与标签参数维持冻结线不变；其他 40/42/52vp 小控件仍使用上表 6vp 共享玻璃。

### 浅色玻璃

| Token | 值 | 作用 |
| --- | --- | --- |
| `bottom_tab_bar_bg` | `#26FFFFFF` | 共享采样基底 |
| `bottom_tab_bar_highlight` | `#D9FFFFFF` | 细高光边缘 |
| `bottom_tab_bar_shadow` | `#300D1B2A` | 中性外阴影 |
| `bottom_tab_selected_bg` | `#2064748B` | 可辨认的中性灰选中胶囊 |
| `bottom_tab_selected_glow` | `#240D1B2A` | 低强度选中阴影 |

浅色模式不能让选中胶囊与页面背景融为一体，也不能用不透明白色切断下方内容。

### 深色玻璃

| Token | 值 | 作用 |
| --- | --- | --- |
| `bottom_tab_bar_bg` | `#18000000` | 低强度烟熏黑采样基底 |
| `bottom_tab_bar_highlight` | `#1AFFFFFF` | 10% 白的克制细边缘 |
| `bottom_tab_bar_shadow` | `#66000000` | 黑色外阴影 |
| `bottom_tab_selected_bg` | `#0A5B8FF9` | 极淡品牌蓝选中胶囊，不叠白色 |
| `bottom_tab_selected_glow` | `#245B8FF9` | 低强度蓝色局部光晕 |
| `brand_primary` | `#5B8FF9` | 深色模式选中图标与文字 |

深色模式的目标是“烟熏底 + 蓝色语义 + 微弱蓝光 + 细白边”。禁止恢复 `#C2FFFFFF` 一类高亮白边，禁止在选中胶囊上再叠加白色半透明背景。旧 `hds_floating_action_*` 资源不是共享组件的规范入口；正式圆形按钮仍须引用上述 `bottom_tab_*` token。

## 组件几何

| 组件 | 尺寸与规则 |
| --- | --- |
| 底部 Tab 托盘 | 288×56vp，四个 72vp 槽位，64×50vp 移动指示器 |
| 首页 FAB | 52×52vp；系统 `plus` 23vp / 900；可拖动 |
| 返回按钮 | 40×40vp；`chevron_left` 28vp / 700 |
| 搜索输入与提交 | 均高 42vp；提交图标 `arrow_up` 24vp / 800，旋转 90° |
| 回复输入与发送 | 均高 42vp；`arrow_up` 24vp / 800，始终品牌蓝，无第二层蓝圆底 |
| 标题栏分段 | 单项 46×30vp，标签 12vp，满圆胶囊，整体上移 2vp |
| 搜索范围分段 | 单项 52×32vp，紧凑满圆胶囊 |
| 发帖发布按钮 | 高 40vp，圆润单层玻璃胶囊 |
| 发帖板块 Chip | 40vp 满圆胶囊，三列网格；未选中烟熏玻璃底 + 1.25vp 高光边，选中品牌蓝底 + 品牌蓝边 |

发表主题页布局顺序为：标题输入（48vp）、正文输入（最小 260vp）在上，板块选择器在下；板块名单行省略，不换行。

所有圆形玻璃按钮应共享同一采样、边缘和阴影参数；不同业务场景可以有 40、42、52vp 的明确尺寸，不能随页面临时放大。

## 底部导航冻结线

- 四栏固定为“首页 / 板块 / 搜索 / 我的”，发布入口不进入 Tab。
- 首页使用 ArkUI `Path`，门洞透明、底部横梁封闭；板块、搜索、我的使用系统填充 Symbol。
- 四枚图标在 28×26vp 光学盒中以各自中心统一缩放 0.92，并统一下移 0.7vp；标签为 11vp、16vp 行盒。
- 只允许一个玻璃托盘和一个连续移动指示器，不叠加 Button 默认 pressed/hover 状态层。
- `ImmersiveBottomTabBar.ets` 与关联入口已冻结，修改前必须取得用户明确同意；交付前运行 `scripts/CheckBottomTabVisualLock.ps1`。

## 列表与内容排版

- 首页仅保留“标题优先”和“作者优先”。标题优先头像 48vp；作者优先头像 38vp。
- 两种首页主题标题均为 17vp / 500；作者、回复、时间为 13vp。
- 板块目录名和具体板块主题标题与首页相同，均为 17vp / 500。
- 主题详情主楼和回复使用头像居左、作者/正文居右；正文 15vp，长文行高 25vp。
- 列表使用真实头像；仅在缺失或加载失败时使用首字母回退。

## 交互与可访问性

- 分段控件既支持点击，也支持水平拖动；选中状态必须先更新本地响应式状态，再持久化。
- 图标按钮提供 `accessibilityText`；纯装饰节点不承担点击语义。
- 默认 pressed/hover 层若造成双轮廓或黑闪，应关闭并由唯一移动指示器表达状态。
- 布局检查不仅看逻辑坐标，还要看可见边界、文字光学居中、状态栏安全区和深浅色对比。
